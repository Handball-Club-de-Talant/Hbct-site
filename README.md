# Site HBCT — première version
Fichiers : index.html, style.css, script.js

## Mise en ligne gratuite
1. Créez un dépôt public sur GitHub.
2. Envoyez les 3 fichiers à la racine.
3. Dans Settings > Pages, choisissez "Deploy from a branch", branche main, dossier /root.
4. Enregistrez : GitHub fournira une adresse gratuite en *.github.io.

## À personnaliser
- Logo réel du HBCT
- Photos des équipes
- coordonnées du club
- lien HelloAsso
- calendrier officiel
- logos partenaires
- réseaux sociaux
- formulaire de contact réel
